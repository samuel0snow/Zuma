## 彩球与发射台视觉升级

2026-10-13 根据实际界面反馈，使用内置 imagegen 生成透明彩球和发射台。旧 SVG 保留为历史候选，页面改用 `web/assets/balls/gemstone/{red,green,blue,yellow,purple}.webp` 和 `web/assets/launcher/pedestal-painted.webp`。彩球使用宝石纹理、螺旋雕刻和旧铜镶边；底座采用石材、苔痕和旧铜雕饰。按用户后续要求，GUI 不再叠加可见字母，保留颜色无障碍标签和图片加载失败时的纯色回退；CLI 字母不变。各球最多携带一种特殊属性，颜色和规则不由图片决定。
