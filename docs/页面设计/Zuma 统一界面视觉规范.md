# Zuma 统一界面视觉规范

本规范适用于玩法选择、地图选择、关卡选择、游戏舞台、结束结果、玩法说明和回合复盘。统一文字、间距、卡片与交互，保留森林遗迹、石材轨道、古金发射台和五色宝石球的视觉体系。

## 1. 视觉重点

- 游戏舞台是游戏页的主要内容；侧栏承担等待球、下一颗球、操作和结果。
- 选择页留出阅读空间；游戏页完整显示轨道；复盘页可以展开为长流程。
- 精美背景提供环境氛围，正文和操作保持清楚；局部遮罩控制对比度。
- 普通界面反馈保持稳定，发射、推移和消除动画根据游戏事件播放。

## 2. 统一变量

`web/style.css` 顶部集中定义变量。颜色、字体、间距、圆角、面板和按钮共享这些变量。

| 类型 | 变量与用途 |
| --- | --- |
| 背景与正文 | `--bg` 深森林底色；`--text` 米白正文；`--muted` 灰绿说明 |
| 主要操作 | `--jade` 玉绿，用于开始、重新开始、模式选中与连接状态 |
| 重点提示 | `--gold` 古金，用于小标题、焦点和终点提示 |
| 失败与效果 | `--danger` 暖珊瑚色，用于失败与特殊属性事件 |
| 面板与描边 | `--surface-card`、`--surface-helper`、`--surface-control`、`--border-card`、`--line` |
| 圆角 | 控件 8px、卡片/舞台 12px、属性小标签 4px |
| 间距 | 4、8、12、16、20、24、32、40、48、64px；统一使用 `--space-*` |
| 动效 | `--motion-fast: 160ms`，用于颜色、描边和阴影反馈 |

五色球的颜色承担玩法识别，使用已有宝石素材。不要将所有界面标题、边框分别染成五种球色。

## 3. 文字层级

| 内容 | 字号 | 字重 |
| --- | --- | --- |
| 选择页主标题 | 32px；首页宣传标题 36px | 700 |
| 游戏关卡标题 | 24px | 700 |
| 卡片标题 | 18px | 600 |
| 模块标题、模式名称 | 16px | 600 |
| 得分与回合数字 | 18px，等宽数字 | 700 |
| 正文、主要按钮 | 13px | 400 / 600 |
| 说明、次级操作 | 12px | 400 / 500 |
| 小标题、辅助标记 | 11px | 500 |

文字采用微软雅黑等系统中文字体。正文行高 1.7，标题 1.4；小字只用于辅助内容。属性标签、SVG 标注属于地图或缩略图的几何元素，可以按场景比例缩放，不强行套用界面正文大小。

## 4. 三种界面层级

### 主舞台

完整展示地图、彩球、发射台、瞄准线和效果。使用遗迹背景、12px 圆角、细描边和轻阴影。舞台之外不再增加包住全部内容的大块面板；结束时保持舞台尺寸和球的色彩亮度。

### 辅助卡片

玩法选择容器、地图卡、关卡卡、等待球卡、结果卡和复盘卡共享圆角、描边、阴影与内边距。辅助卡片以森林绿色面板为基础，结束结果根据胜利或失败使用适当的语义色。

卡片内边距通常 24px，侧栏为 20px，较矮桌面为 16px。模块间距为 20/24px，标题与内容间距为 12/16px。

关卡卡片中预览球数不同时，说明和开始按钮仍沿同一底线对齐。选择卡被悬停时，也保留已经选中的玉绿状态。

### 控件与标签

按钮使用 8px 圆角；属性标签使用小尺寸古金标签。分隔线保持低对比度。卡片内部使用轻量内容区，避免反复套用厚重面板。

## 5. 按钮与状态

| 类型 | 使用位置 | 规则 |
| --- | --- | --- |
| 主按钮 `.primary` | 开始、选择地图、重新开始 | 玉绿底、深绿字，最小高度 40px |
| 次按钮 `.secondary` | 丢弃、查看复盘 | 森林绿底、米白字、细描边，最小高度 40px |
| 轻按钮 `.quiet` | 返回、说明、结束、重启、跳过、收起 | 透明底，最小高度 32px，悬停显示轻背景 |
| 选择卡 | 玩法和地图入口 | 选中用玉绿描边；悬停轻微强调描边与阴影 |

- 所有按钮具有明确的键盘焦点：古金色 2px 外框。
- 悬停只改变背景、文字、描边或轻阴影；不放大整个按钮或移动卡片。
- 禁用状态降低透明度，停止悬停反馈。
- 选择状态通过 `aria-pressed` 和可见勾选同时表达。
- 动画播放期间沿用现有操作锁定和跳过规则。

## 6. 桌面布局与几何边界

验证尺寸为 1280×720、1366×768、1920×1080。场景以整张地图等比例缩放，侧栏宽度 260px，舞台与侧栏间距 24px。页面文字、卡片间距和按钮尺寸按桌面空间调整，正常游戏及结束画面完整显示。

舞台球径、球心间距、发射台定位和瞄准计算仍来自服务端地图几何。直线/S 形球径 68，螺旋球径 44；这些值不能被通用卡片或按钮样式覆盖。临时飞球与特效放在舞台裁切层内。终点根据容量定位于最后合法球位与首个超限球位之间。

复盘保存实际结束状态与事件，允许自然滚动；复盘缩略图使用同一地图与终点绘制方式。

## 7. 样式维护规则

`web/style.css` 按以下顺序维护：变量和基础 → 按钮 → 页头/选择页 → 彩球 → 游戏布局和侧栏 → 地图绘制/动画 → 复盘 → 对话框 → 桌面空间适配。

- 一个组件只保留一套基础声明；语义状态与媒体适配集中放置。
- 移除已弃用的编号间隙、旧直线 CSS 轨道、底部操作栏和全宽结束横幅规则。
- 新需求直接修改所属组件，不继续在文件尾部追加覆盖补丁。
- 文字、间距与圆角优先使用变量；几何坐标和球体尺寸保持独立。
- 不为普通辅助卡片叠加持续动画或多层模糊。系统减少动态效果设置继续生效。
