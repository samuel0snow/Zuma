## 二、怎么找的（可复查）

检索站点：Kenney（kenney.nl）、OpenGameArt、ambientCG、Google Fonts、GitHub（game-icons / tabler / lucide）。
每一步都做了链接实测：先 `Invoke-WebRequest -Method Head` 看状态码，再用 GET 真下载，检查文件头
（zip 应为 `PK`、PNG 应为 `89504E47`）与图片实际尺寸，避免把错误页当素材。
许可逐条打开素材页确认，来源见 `CREDITS.md` 中每条记录的"许可原文要点"。

## 三、逐项候选

### 1. 五色彩球

**首选：Kenney Rolling Ball Assets 派生五色**（CC0，[kenney.nl/assets/rolling-ball-assets](https://kenney.nl/assets/rolling-ball-assets)）

- 原包只有红、蓝两色球，各 4 个变体；`ball_blue_large.png` 为 128×128 透明 PNG，扁平化球体 + 左上高光。
- 派生做法（`tools/stage-art-assets.py` 的 `hue_shift_ball`）：水平镜像把高光移到左上，再只替换饱和度足够像素的
  色相，保留原有 S/V 与高光。**五颗球的轮廓、高光位置、明暗层次完全一致**，正好满足"统一尺寸、中心点、高光"的要求。
- 输出：`balls/kenney-5color/{red,green,blue,yellow,purple}.png`，128×128，合计 26 KB。

| 备选 | 许可 | 规格 | 点评 |
| --- | --- | --- | --- |
| [Egg Blast](https://opengameart.org/content/egg-blast)（OnTheBus） | CC0 | 76×76 透明，正好红/绿/蓝/黄/紫五色 | 现成五色、开箱即用；但造型是"带脉络的蛋"，与翡翠石庭风格不搭。已收进 `balls/egg-blast/` 备用 |
| [Shiny Orbs 64x64](https://opengameart.org/content/shiny-orbs-64x64)（Mumu） | CC0 | 64×64 | 发光的虹膜状光球，不是实心球，不适合当球体 |
| [200+ Magic Orbs](https://opengameart.org/content/200-magic-orbs-psionic-dew)（Varkalandar） | CC-BY 3.0 / **CC-BY-SA 3.0** | 大图 | 好看但含 ShareAlike，课堂打包再分发会牵连，未采用 |
| [Ball Set [SVG]](https://opengameart.org/content/ball-set-svg) | **GPL 3.0** | SVG | 许可不适合本项目，未采用 |

**规格差距（如实说明）**：需求文档写 256×256，实际拿到的高质量现成球是 128×128，页面显示 32–84px，
128 在普通屏足够、2× 高分屏会略软。要真正的 256 需要矢量重绘——Kenney 原包里有
`Vector/rollingBall_vector.svg`（CC0，矢量球体），可以按需导出任意尺寸，本次没有做。

### 2. 特殊属性图标（Back / Stop / Boom）

**首选：[game-icons.net](https://game-icons.net)（CC BY 3.0，需署名）**，实心风格统一，32px 下仍可辨认：

| 用途 | 选中 | 为什么 |
| --- | --- | --- |
| Back | `back-forth` | 双向折返箭头，最贴近"双回转箭头"的语义；`return-arrow` 只有单回转 |
| Stop | `stopwatch` | 停滞/等待语义清楚，纯图形无文字；`stop-sign` 自带 "STOP" 英文，与旁边的中文标签重复 |
| Boom | `bright-explosion` | 爆点 + 四射光芒，最小尺寸下仍是一团火；`unlit-bomb` 的炸弹轮廓在 32px 会糊成一个圆 |
| 胜利 | `laurel-crown` | 花环 + 冠，正是需求里的"胜利花环" |
| 失败 | `cracked-glass` | 碎裂纹章，比 `shatter` 更"章" |

另存了 7 个备选在 `icons/alternatives/`（含炸弹、暂停键、STOP 牌、碎裂三选）。**CC BY 3.0 要求署名**，
写法见 `CREDITS.md`；不想署名就整套换成下表的线条图标。

**无署名义务备选**：`icons/tabler/`（MIT，7 个）、`icons/lucide/`（ISC，9 个），含 `arrow-back-up`、`player-pause`、
`circle-stop`、`bomb`、`trophy` 等，线条统一，适合整体切换。许可分别见
[Tabler LICENSE](https://github.com/tabler/tabler-icons/blob/main/LICENSE) 与
[Lucide LICENSE](https://github.com/lucide-icons/lucide/blob/main/LICENSE)。

### 4. 动效

**白色可调色粒子（Kenney Particle Pack，CC0，512×512 透明）**——适合"五色共用基础素材并调色"：

| 用途 | 文件 | 说明 |
| --- | --- | --- |
| 消除闪光 | `effects/flash/flare-01.png`、`star-03.png`、`spark-05.png`、`twirl-01.png` | 白色，用 CSS `filter` 上色或 canvas 叠加 |
| Stop 光环 | `effects/ring/circle-01.png`、`circle-04.png` | 同心圆环，可直接循环缩放 |
| Boom 余痕 | `effects/boom/scorch-01.png`、`muzzle-03.png` | 焦痕与迸发 |
| Back 尾迹 | `effects/trail/trace-02.png`、`trace-04.png` | 白色细长拖尾 |

**序列帧（均为 CC0）**：

| 用途 | 目录 | 帧数 | 单帧 | 原素材 | 建议播放 |
| --- | --- | --- | --- | --- | --- |
| 普通消除闪光 | `effects/flash-seq/00-11.png` | 12 | 128×128 | OGA rubberduck `flat_effect/magic` | 30–40fps，播完即止（≈300–400ms） |
| Boom 爆破 | `effects/boom-seq/00-11.png` | 12 | 128×128 | OGA rubberduck `explosion/fire` | 30fps（≈400ms），可配 `shockwave-seq` |
| Boom 冲击环 | `effects/shockwave-seq/00-07.png` | 8 | 128×128 | OGA rubberduck `shockwave/magic` | 20–25fps，播完即止 |
| Stop 光环 | `effects/ring-seq/00-07.png` | 8 | 128×128 | OGA rubberduck `ring/magic` | 20fps 循环 |
| 发射/爆破闪光（256px） | `effects/muzzle-flash-seq/00-11.png` | 12 | **256×256** | OGA zisongbr `16 toon muzzle flash` | 25–30fps，播完即止 |

序列帧来源：[25 special effects rendered with blender](https://opengameart.org/content/25-special-effects-rendered-with-blender)（rubberduck，CC0）、
[16 toon muzzle flash](https://opengameart.org/content/16-toon-muzzle-flash)（zisongbr，CC0）。
原始素材是 20–40 帧，本次等距抽到 8–12 帧以贴合需求文档的帧数区间；**要更细腻可以从下载目录取全帧重抽**。

两点如实说明：
1. `*-seq` 的配色是素材自带的紫/橙，不是白底，调色后可能发浊。要五色匹配，白色粒子（上一节）
   或"把序列帧先转灰度再用 CSS 上色"更稳。本次没有做灰度重制。
2. Boom 序列帧原生 128×128，与需求里的 256 有差距；256 那套是卡通枪口闪光（`muzzle-flash-seq`），风格偏欧美卡通，
   与石庭方向不完全一致，二选一即可。

## 五、落地注意事项

1. **服务端白名单必须先扩展**：`src/server/main.cpp` 目前只放行 `index.html`、`style.css`、`app.js`
   （`for (const auto& asset : {...})`，第 78 行附近）。把资源放进 `web/assets/` 后**不会自动可访问**，
   需要同时加白名单与对应 MIME（`.png/.jpg/.svg/.webp`），并留意路径穿越校验。
2. **署名**：`icons/` 与 `icons/alternatives/` 是 CC BY 3.0，发布时要在页面"关于"或 README 里保留署名；
   `icons/tabler/`、`icons/lucide/` 只需随包附许可文本。CC0 素材无义务，但本项目仍在 `CREDITS.md` 里如实记录。
3. **体积**：本目录合计 1.8 MB。首屏只加载球 + 图标 + 轨道约 130 KB，动效按需加载，符合需求文档的 2 MB / 5 MB 目标。
   最大单块是 `effects/muzzle-flash-seq`（约 800 KB），不用就删。
4. **命名与编号**：沿用需求文档约定（`balls/red.webp`、`effects/boom/00.png`）。
   本目录用的是 `balls/kenney-5color/red.png`，是为了保留两套候选；确定方案后建议按文档收敛为 `balls/red.png`。
5. **不要烘焙字母**：所有图标与球体都不含 R/G/B/Y/P 字母，字母继续由 HTML 叠加，符合需求文档要求。
6. **调色方式**：白色粒子/矢量图标优先用 CSS `filter`（`hue-rotate` / `drop-shadow`）或 canvas 上色；
   位图序列帧若需要换色，建议先转灰度再乘色，避免直接色相旋转出现脏边。

## 六、复现与再生成

```powershell
# 素材归档（已下载，重跑会用网络）：E:\Download\Zuma-美术资源
# 重新整理到 web/assets（需要 Pillow）
cd D:\Github_projects\Zuma
python tools\stage-art-assets.py
```

脚本只做四件事：复制（图标/粒子/徽章）、派色（五色球）、等距抽帧（序列帧）、裁切（轨道横带）。
想换图标或换帧数，改脚本顶部的映射表即可。
