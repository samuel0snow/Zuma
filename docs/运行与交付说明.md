# Zuma 运行与交付说明

## Windows 运行包

解压 `Zuma-windows-x64.zip`，保留其中 `levels/`、`web/` 和 `third_party/` 的相对位置。

- 双击 `启动GUI.cmd`，或在解压目录运行 `zuma_gui.exe`。浏览器访问 `http://127.0.0.1:8080`。
- 端口占用时运行 `zuma_gui.exe --port 8082`，访问 `http://127.0.0.1:8082`。
- 在服务终端按 Ctrl+C 停止 GUI。仅关闭网页标签不会停止服务。
- 双击 `启动CLI.cmd`，或运行 `zuma.exe`，可独立玩命令行版本。
- GUI 和 CLI 的进度彼此独立；退出后不保存进度。重启返回模式选择。

本运行包面向 Windows 10/11 x64，由 MinGW 静态链接构建，不需要编译器、Node、Python 或联网下载资源。浏览器建议使用支持 Web Animations API 的现代 Chrome/Edge/Firefox。没有动画支持或资源缺失时仍显示最终游戏状态；系统开启“减少动态效果”时直接展示最终状态。

## 动画与操作

发射和丢弃后，先由 C++ 处理完整回合，网页依次展示插入、消除、连锁、属性、等待球及弹药变化。播放期间禁用游戏操作，“跳过动画”可立即结束播放；动画结束后以服务最终快照校正，才允许下一步。

连接异常时不会自动重发发射。点击“重新连接”同步服务状态；另一页面改变游戏时，当前页下一次操作会提示并同步。游戏结束后只能重新开始，不能再发射或丢弃。

## 源码包

解压 `Zuma-source.zip` 后在根目录执行：

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
ctest --test-dir build --output-on-failure
.\build\zuma_gui.exe
```

MSVC 开发者终端使用 `cmake -S . -B build` 与 `cmake --build build --config Release`，程序位于 `build/Release/`。CMake 构建复制关卡、页面、资源和许可，不需要 npm 构建。

Python 存在时增加真实 HTTP 测试；动画浏览器验收脚本和执行方式见验证记录。美术整理脚本需要 Pillow 和原始素材归档，仅用于可选再生成；源码包已经包含最终素材，正常构建不依赖个人下载目录。

## 许可与素材

保留 `third_party/` 的库许可与 `web/assets/CREDITS.md` 的美术署名。页面页脚可查看素材来源。Kenney 球体与 OGA 特效的派生记录、生成背景提示词和自绘底座记录均保存在素材目录文档中。

## 打包

在项目根目录先构建与验证，再运行：

```powershell
python tools/package-release.py
```

默认输出到 `build/releases/`，生成运行 ZIP、源码 ZIP；运行 ZIP 内含 SHA256 文件清单。工具使用独立临时目录组装，不混入以前打包遗留的资源。课程提交时可按“姓名-学号”重命名外层压缩文件；姓名、学号及课程报告 PDF 由提交者填写准备，本说明不代填个人信息。

目前验证环境为 Windows x64；其他操作系统及 MSVC 有构建入口，但未以本机测试结果冒充跨平台实测。
