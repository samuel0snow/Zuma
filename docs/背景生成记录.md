# 背景与底座制作记录

2026-10-13 使用内置 imagegen 制作背景，最终文件为 `web/assets/backgrounds/courtyard.webp`。原生图像尺寸为 1672×941，没有把它冒充为 2560×1440；网页以 cover 裁切展示，叠加暗色渐变保护文字对比度。保存原生 PNG 的生成位置由工具管理，项目内保留最终 WebP，不依赖外部路径运行。

提示词：

> Create a production-ready game background image for a Chinese Zuma marble puzzle web game called Five-Color Cloister. Stylized 2D painted concept art, wide landscape 16:9 composition. Quiet ancient stone courtyard at dusk, deep forest green and jade green tones, subtle weathered stone floor, restrained warm antique gold edging on architectural fragments. Only the far left and far right edges contain small mossy pillars and delicate carved stone relief. Broad central 70% of the image remains uncluttered dark low-contrast stone and soft atmospheric gradients, reserved for readable game UI. No balls, no people, no animals, no frog, no launcher, no text, no lettering, no logo, no interface, no symbols or buttons. Soft painted textures rather than photographic noise; consistent with simple flat jewel-colored game sprites. Ambient soft light from the upper left, corners slightly darker, no bright focal point in the middle. Crisp finished original artwork, suitable as a decorative background behind opaque dark-green UI panels.

内置生成完成后，使用 `tools/prepare-d-assets.py --background 原生PNG路径` 进行 WebP 编码；该过程仅做格式转换，没有重新构图或放大。

发射台底座为本项目直接编写的 512×512 透明 SVG：`web/assets/launcher/pedestal.svg`。使用阶梯式石座、椭圆球槽、暖金边线，球由网页独立叠加。小屏布局不显示底座，保留发射操作空间。
