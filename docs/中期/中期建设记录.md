## 中期建设记录：A / B / C（2026-10-13）



- **A 核心适配**：Ball 增加稳定 ID；等待球入轨、Back 回退及再次入轨保持身份。Game 提供完整轨道/等待区快照与结构化事件，包含球 ID、清除范围、得分变化和各阶段状态。原有 CLI 文字与规则继续工作。

- **B 本地服务**：新增 zuma_gui，复用 zuma_core；提供关卡列表、游戏状态、创建、发射/丢弃和重启 API。仅监听 127.0.0.1；使用版本、会话 ID 与唯一 requestId，重复请求不重复推进，旧状态请求被拒绝。缓存最近 64 个成功请求；淘汰后旧请求仍会因版本/会话失效被拒绝。

- **服务边界**：请求体 8KB、JSON 嵌套 16 层、GUI 每字段及容量最多 4096；位置严格接受整数。静态文件按白名单提供，同源检查及自定义 JSON 请求头防止跨来源操作。GUI 限制用于保护网页和快照资源，不改原始附件和 CLI 容量规则。

- **C 静态交互**：HTML/CSS/JavaScript 实现模式、关卡、游戏及结果界面，各属性 10%（总概率 30%）说明、球下属性标签、红色效果提示、丢弃、横向滚动、刷新恢复与重启回模式页。前端只展示核心结果，不自行实现消除规则。

- **异常处理**：请求期间禁用操作，连接异常后同步权威状态，不自动重新发射；支持重新连接。双页面共享单局，旧会话/版本同步时有提示。服务重启不保留旧局。

- **构建**：GUI 的 HTTP/JSON 依赖固定版本，附源文件与 MIT 许可，默认构建复制网页、关卡和许可资源。为本机混装 MinGW 增加经过编译探测的 CRT ABI 兼容分支，不改系统编译器文件。

- **验证**：原有规则、核心/API 固定种子一致性与真实 HTTP 三组测试通过；实际浏览器验证两关操作、胜负、空轨道、刷新、键盘、重启、断线不重发、快速双击、双页面冲突和 390px 小屏。详见 [中期验证记录](../审核记录/中期验证记录.md)。

- **阶段边界**：D 的完整回合动画尚未实现。当前彩球、轨道和按钮由 CSS 绘制，后续资源与交付规格见 [Zuma 美术资源需求.md](../美术资源/Zuma%20美术资源需求.md)。



完整架构、接口与后续阶段见 [Zuma 中期建设方案.md](Zuma%20中期建设方案.md)。



## 中期 D / E 完成记录（2026-10-13）



### D：完整回合动画与美术



- 新增 `web/animation.js`，按核心结构化事件播放插入、普通/连锁消除、Boom、Stop、Back、等待入轨和弹药更新。移动依据球 ID 与阶段快照，前端不自行计算消除规则。

- 播放期间锁定发射、丢弃和重启；允许跳过动画。系统减少动态效果、后台页面、动画 API 不可用或播放异常时直接落到最终快照，清理临时动画元素。

- 每回合播放结束后再读取当前服务状态，处理另一页面在播放期间推进或重启的情况，避免旧会话界面覆盖新局。

- 球体从 Kenney 原始矢量提取、镜像与派色，256px SVG 画布可缩放；属性图标派生透明金色版本；普通消除、Boom、Stop 使用已整理的图集。背景由内置 imagegen 制作并转 WebP，底座为 512px SVG 自绘。原始候选不覆盖。

- 服务扩展明确资源白名单与对应 MIME，不提供任意目录挂载。素材失败时保留颜色和字母；署名通过网页页脚及 CREDITS.md 提供。
