# 项目目录与清理记录

## 目录职责

| 目录 | 内容 |
| --- | --- |
| `src/`、`include/` | CLI、共享规则、地图与本地网页服务源码 |
| `levels/` | 当前关卡配置，新增关卡放在这里 |
| `web/` | 当前网页及运行所需素材 |
| `tests/` | 规则、地图、接口、动画、浏览器及交付测试 |
| `tools/` | 资源制作、浏览器验证及交付打包工具 |
| `third_party/` | 构建所需第三方源码和许可 |
| `docs/` | 分阶段方案、建设与审核记录、页面设计、美术资源和课程报告 |
| `build/` | 本机编译产物、运行资源副本及发布包，不纳入版本控制 |
| `Zuma/` | 用户原始说明和资料，不纳入版本控制；不是运行时关卡目录 |
