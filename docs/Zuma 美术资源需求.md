# Zuma 美术资源需求：D 阶段准备

本文保留最初的美术需求；D 阶段已接入筛选后的球体、图标、轨道与动画资源，并制作背景、底座。资源失效时仍有 CSS/文字回退，玩法与接口不受素材影响。

## 视觉方向

沿用当前“翡翠绿回廊 + 暖金装饰 + 五色彩球”的方向：幽静石庭、轻微遗迹纹样，彩球明亮且容易辨认。背景降低对比，互动按钮与彩球优先。先制作一套完整基础资源，再扩展关卡主题。

球上的 R/G/B/Y/P 字母、得分、回合数、属性名称、位置编号由网页绘制，不烘焙到图片中，便于缩放、翻译和无障碍识别。素材不决定球的碰撞或插入位置，交互范围由页面布局管理。

## 第一批：优先准备

| 资源 | 数量 | 建议规格 | 制作要求与用途 |
| --- | --- | --- | --- |
| 五色彩球 | 5 张 | 256×256，透明 PNG 或 WebP | 红、绿、蓝、黄、紫；统一尺寸、中心点和左上高光，球形有效区域相同。页面实际显示约 32–84px，缩小后轮廓仍清楚。字母由 HTML 叠加。 |
| 特殊属性图标 | 3 张 | SVG 优先；位图 128×128 透明 | Back 双回转箭头、Stop 停滞符号、Boom 炸弹/爆破；可单色使用，旁边仍保留文字。图标不遮挡球色。 |
| 关卡背景 | 1 张起步 | 2560×1440，WebP，另备竖屏 1080×1920 | 暗绿石庭与微弱光照，中央区域留白，适应裁切。不要在中心或右侧发射台后绘制高对比物体。 |
| 轨道纹理 | 1 套 | 横向可平铺 512×128，透明或无缝底图 | 保持直线轨道适配，单独入口/出口装饰可各做 256×256 透明图。不能把固定数量的球槽画死。 |

这四类足以替换当前 CSS 占位视觉。先交付球和图标，就可以开展 D 阶段的反馈动效。

## 第二批：完整动效与装饰

| 资源 | 数量 | 建议规格 | 用途 |
| --- | --- | --- | --- |
| 普通消除闪光 | 1 套，可调色 | 单帧 128×128，8–12 帧透明序列，或 SVG/CSS 特效参考 | 彩球缩小、光点散开，五色共用基础素材并调色。 |
| Boom 爆破 | 1 套 | 单帧 256×256，8–12 帧透明序列 | 爆点及冲击环；清除范围由结构化事件决定，特效不遮住下一步结果。 |
| Stop 光环 | 1 套 | 128×128，6–8 帧可循环 | 暂停标记或球外环；剩余回合文字独立显示。 |
| Back 尾迹 | 1 套 | 256×64 透明，或矢量箭头参考 | 回退方向提示，移动球仍使用同一球 ID。 |
| 发射台装饰 | 1 张 | 512×512，透明 | 与当前右侧面板适配的底座；当前球可更换，不能画死。可选，不要求蛙类角色。 |
| 胜利 / 失败徽章 | 各 1 张 | 256×256，透明 | 胜利花环 / 失败碎裂纹章；保留网页上的可读结果文字。 |
| 标题标志 | 1 套 | SVG + 512px 透明备份 | ZUMA 与五色回廊的统一字标，小尺寸标志仍清晰。 |

建议动效时长：发射 150–250ms，单次消除 200–350ms，特殊效果 300–500ms。完整连锁较长时可加速或跳过；系统设置减少动态效果时直接显示最终状态。具体时长需 D 阶段实际游玩调整。

## 交付约定

- 文件建议放 `web/assets/`，英文命名：`balls/red.webp`、`effects/boom/00.png`、`icons/back.svg`、`backgrounds/courtyard.webp` 等。
- 透明图不可带白色底边；同类图片画布和锚点统一居中。序列帧使用两位编号，给出帧数、帧率与是否循环。
- 如果提供精灵图，额外提供单帧尺寸、行列数、播放顺序和锚点表；每帧之间留少量透明边，避免缩放串色。
- 提供可编辑源文件与最终导出文件，并说明来源及使用许可，以便随课堂项目打包。
- 建议首屏实际加载资源合计不超过 2MB；动效按需加载，总素材量以 5MB 左右为第一版目标。数字是优化目标，不是玩法限制。
- 背景图不承担可读文字；资源缺失时保留 CSS 彩球和文字回退，不阻断游戏。

## 资源完成后的下一步
